# Repo Codex Rules

- For non-trivial chess-harness implementation work, update `PRD.md` and `PRD_CHECKLIST.md` before changing code, keep checklist status current while working, and mark the relevant items complete only after focused validation.
- For viewer work, preserve the local account-free workflow, persisted UI preferences in `localStorage`, FastChess live mirror compatibility, fixed live-board behavior during concurrent `-Concurrency` runs, collapsed-by-default Engine Config, and the no-fallback-move engine boundary.
