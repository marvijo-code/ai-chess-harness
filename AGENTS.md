# Repo Codex Rules

- For non-trivial chess-harness implementation work, update `PRD.md` and `PRD_CHECKLIST.md` before changing code, keep checklist status current while working, and mark the relevant items complete only after focused validation.
- For viewer work, preserve the local account-free workflow, persisted UI preferences in `localStorage`, FastChess live mirror compatibility, fixed monotonic live-board behavior during concurrent `-Concurrency` runs, the legacy `-p` compatibility alias for concurrency, clickable in-progress match switching, collapsed-by-default Engine Config, and the no-fallback-move engine boundary.
- Keep FastChess runner engine selection simple and explicit: prefer `fastChess.player1` / `fastChess.player2` and `-Player1` / `-Player2` for new work, while preserving `-LearningEngine zero` as a compatibility shortcut. Keep `Codex-chess-zero` as a separate fast first-principles learner with a deliberative human-reasoning controller and PUCT only as calculation support. Keep each engine's memory, knowledgebase, skills, and tools under its own engine folder, and pass autolearn an explicit engine name/context so it does not write learner state or create cheating exact-move artifacts.
- Prefer the repo-local `.\run-zero-climb-loop.ps1` for immediate back-to-back `zero-stockfish-climb` training rounds; the automation should run every 15 minutes as a reporter/watchdog: read automation memory, run `python .\tools\ensure_zero_climb_loop.py --profile gm-sprint --wait-seconds 20`, verify/start the loop, inspect current climb artifacts, update automation memory, report status, and exit. Keep each round bounded, prevent overlapping loop instances with the loop lock, scale Zero visits/self-play/promotion to local headroom, focus on the current failed gate, preserve readable wisdom deltas, and keep all external engines/games/books/tablebases evaluation-only.
- For learner/Zero speed work, prefer capped prompt payloads, lower configured per-turn learner/critical/Zero effort, and deferred live-watch concept synthesis before increasing FastChess `-Concurrency` on CPU-bound machines.
