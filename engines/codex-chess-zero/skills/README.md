# Codex-chess-zero Skills

Zero mode keeps `UseSkills=false` by default during move selection so it learns from first principles and post-game feedback rather than curated opening knowledge.

Post-game autolearn may still maintain `self-play-concepts/SKILL.md` as a research artifact. Generated skills must stay concept/feature based and must not contain exact FEN-to-move answers, opening books, tablebases, Stockfish/Lc0/Maia PVs, or human-game imitation labels.
